The first release of fftui, a terminal interface for FFmpeg that runs on Linux, macOS, Windows, and the BSDs.

fftui uses the `ffmpeg` and `ffprobe` you already have (4.4 or later). Open files with `fftui video.mp4 *.mkv`, pick a task, and watch the job run. Every task shows the exact FFmpeg command it will run, so you can learn from it, copy it, or edit it.

## What it does

- **Media info**: container, duration, size, bit rate, and every stream (codec, resolution, frame rate, audio layout, language, subtitles) from `ffprobe`.
- **Tasks**, each a short form with sensible defaults:
  - Convert video to H.264, H.265, VP9, or AV1, with quality and speed choices
  - Change container (MP4, MKV, MOV, WebM) without re-encoding
  - Compress to a target size, with two-pass encoding for H.264
  - Extract audio as MP3, AAC, Opus, FLAC, or WAV
  - Trim, with a fast stream-copy cut or an exact re-encoded one
  - Resize or lower the frame rate
  - Make a GIF with a generated palette
  - Choose streams, such as one audio language or no subtitles
  - Custom command, for anything else
- **Hardware encoders**: every form lists the NVENC, Quick Sync, AMF, VA-API, VideoToolbox, and other encoders your FFmpeg build has. Each run starts on the software encoder; if a hardware encoder fails for lack of a device or driver, one key reruns the job in software.
- **Batches**: mark several files and run one task on all of them. Jobs run as many at once as the `jobs` setting allows.
- **Jobs screen**: progress bar, speed, size, time left, the live FFmpeg log, cancel (FFmpeg finishes the file cleanly), and a failure message that names the real cause, such as `h264_nvenc: Cannot load libcuda.so.1`.
- **Safe by default**: never overwrites the input, asks before overwriting any other file, deletes half-written outputs of failed jobs, and stops FFmpeg when fftui exits.
- **Settings screen**: edit `jobs`, `output_dir`, `ffmpeg_path`, `ffprobe_path`, and `ascii`, saved to `config.toml` and applied at once.
- **Copy commands** to the clipboard (OSC 52, which works over SSH, plus `pbcopy`, `clip.exe`, `wl-copy`, `xclip`, or `xsel`).
- **Works in limited terminals**: `--ascii` draws with plain ASCII, and colors follow the terminal and `NO_COLOR`.

## Install

Homebrew (macOS and Linux), which also installs FFmpeg:

```sh
brew install part-avocado/tap/fftui
```

Or download the archive for your OS below, or build from source with Go 1.26.7 or later:

```sh
go install github.com/part-avocado/fftui/cmd/fftui@latest
```

The macOS binaries in the archives are not signed. If macOS refuses to open one, run `xattr -d com.apple.quarantine fftui`, or install with Homebrew, which builds it from source.

## Known limits

- Files come from the command line; a file browser inside fftui is planned.
- Hardware encoders are tested only for the arguments they get, not on real GPUs.
